# Q10, run 1

## Prompt, exactly as sent

> Under the Quillbrook Village Hall rules: Four trustees want to attend a committee meeting on 15 November 2026, but one proposes joining by video call from home while the other three attend in person. Do the rules allow a remote trustee to count towards the required quorum, and would that make this meeting quorate?

2. Grep Quillbrook
3. Read reference/hall/hall-trustees.md
4. Grep "quorum|quorate|remote|video|virtual" in reference/hall

## Answer

**The rules don't say, so they don't settle whether the meeting is quorate.**

- **Quorum:** Rule 4.2 says "Four trustees form a quorum." Four trustees want to attend, so the number is met only if the remote trustee counts.
- **Remote attendance:** Rule 6.3 says the rules "do not specify whether trustees may attend remotely." Nothing in the rules either permits or forbids a video attendee counting towards the quorum. I searched all the hall documents for "quorum", "remote", "video" and "virtual". The only hits were rules 4.2 and 6.3.

**If the remote trustee counts:** four are present, which meets rule 4.2. The meeting would be quorate and could take decisions under rule 4.3.

**If the remote trustee doesn't count:** only three are present, which is below quorum. The meeting couldn't validly make decisions.

The rules give no basis for choosing between these. To be safe, you could:
- have the committee agree beforehand, and minute, that remote attendance counts. Check this against the committee's governing document, if there is one, since these rules don't cover the point.
- get a fourth trustee into the room, if one can attend. This removes the question.
- treat any decisions as at risk of challenge if the meeting goes ahead with only three physically present.
