## Answer

**No, a receipt isn't compulsory for this payment.** The threshold is **£10**.

- **Rule:** Section 4.4 of the current fees schedule (`film-fees.md`) says: "The treasurer issues a receipt for payments of £10 or more."
- **Application:** The £9 cash payment is below £10, so the treasurer isn't required to issue a receipt. The rules don't forbid one, though.
- **Date check:** The schedule took effect on 1 March 2025, so it governs a payment on 12 May 2025. The register of committee changes (`film-changes.md`) has no amendment to section 4.4. Its only changes to the fees file concern membership and member admission prices.
- **Archived version:** The archived February 2025 schedule had the same £10 threshold (4.4). It applied only from 1 February to 28 February 2025, so it isn't relevant here.
